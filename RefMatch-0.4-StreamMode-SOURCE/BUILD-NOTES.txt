RefMatch 0.4 Stream Mode — build notes

This revision follows the same core A/B model documented by Stream AB:
- the DAW mix is muted/unmuted by the plugin;
- the reference remains external system audio;
- captured system audio is used only for analysis;
- no Spotify OAuth/login is used.

RefMatch-specific implementation in this source:
- Spotify desktop is controlled locally with macOS Apple Events / Automation.
- ScreenCaptureKit captures system audio while excluding the current DAW process.
- Spotify search currently opens the query in the Spotify desktop app. It does not yet provide Stream AB-style in-plugin search results.
- The current build has not been compiled inside this Linux container because ScreenCaptureKit/AppKit require macOS. GitHub Actions is the compile test.

Expected GitHub artifact name:
RefMatch-0.4-StreamMode-macOS
