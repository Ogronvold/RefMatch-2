RefMatch 0.5.1 — kildekandidat

UPLOAD / INSTALLATION
1. Upload RefMatch-mappen fra denne ZIP til repoets rod og erstat filerne.
2. Erstat .github/workflows/main.yml med denne versions workflow.
3. Vent på grønt build, og hent RefMatch-0.5.1-PluginOnly-macOS under Artifacts.
4. Luk Logic helt. Erstat den installerede RefMatch.component med den nye.
5. Åbn Logic og kontrollér 0.5.1 i pluginet.

A/B
Afspil den ønskede mediekilde én gang, så macOS kender den. A vælger mix,
B vælger reference, og SWITCH skifter. Transporten er fra den fungerende 0.4.4.
Pluginet skal være aktiveret på den kanal/bus, hvis lyd du vil mute.

MATCH EQ
Start Logic-afspilning. RECORD MIX -> lad mixet spille -> STOP MIX.
RECORD REF -> giv eventuelt capture-tilladelse -> lad referencen spille -> STOP REF.
MATCH beregner og aktiverer EQ. Klik A for at høre resultatet på dit mix.
Amount og EQ ON styrer resultatet. Grafen viser filterets respons.
Optag helst flere sekunder. Både MIX og REF skal have mindst 0,5 s brugbart signal.
Profiler og lærte EQ-gains gemmes med projektet. MATCH er en tonal tilnærmelse,
ikke en kopi af Logics algoritme. REF-optagelse kræver, at Logic behandler lyd.

LOOP
Indtast In og Out, f.eks. 0:45 og 1:15, og slå LOOP til. Vælg B for at lytte.
Normal tilstand kræver positionsdata og kontrollerer seek. Hvis den fejler, kan
TIMED vælges: den sender seek med det indtastede interval uden positionsbekræftelse.
Slå Timed-loop fra før trackskift eller pause uden for RefMatch. Seek er afhængig
af medieafspilleren og ikke samplepræcis. Loopfejl må ikke stoppe A/B.

TESTSTATUS
